🗓️ 學期管理與新學期快速建立 ▾

每個登記項目都屬於一個學期，之後才能比較上學期／下學期、跨學年的進退步。新增項目時預設放在「目前學期」，畫面上方「學期」下拉可以切換要檢視／登記哪一學期（也可選「全部學期」）。學期名稱建議用「114上」「114下」這種格式，系統會依學年與上下學期自動排序。

新增科目

📥 建立外科成績貼上區（例如自然老師提供的成績）

不是你自己登記、但名單或分析需要用到的科目，可以在這裡建立一個貼上區：系統會建一張跟其他科目格式相同的工作表，自動帶入座號姓名，並預先建好「期中平時成績、期中考、期末平時成績、期末考」四欄（淡黃色區域；自然老師通常只有平時成績加段考，各自填進對應的欄位，沒有的留空）。把老師給的成績依座號順序貼進去就好，之後分析頁面和獎狀名單都會自動納入。

🏫 建立學期領域成績貼上區（學校系統匯出的成績）

學期總成績的各領域前五名（語文、數學、社會、自然、健體、藝術、綜合、藝才…）以學校系統匯出的表為準。這裡會建一張「領域成績_學期」工作表，把匯出的表整份貼到 A1（含標題列、名次、平均都可以一起貼），再到分析頁面「獎狀名單 → 學期總成績」產生名單。

科目清單

⚖️ 學期成績權重（各科目） ▾

計算分三層：
① 學期成績＝第一次定期考查總成績（期中）× 比例 ＋ 第二次定期考查總成績（期末）× 比例，預設各占一半。
② 每一次定期考查總成績＝平時成績 ＋ 段考分數（期中考或期末考），預設各占一半。
③ 平時成績＝紙筆測驗（平時測驗）＋ 作業（習作／學習單）＋ 課堂表現（發言／參與／口試），比例依各科學校公布的評量方式（例如國語、數學、社會 40／35／25；綜合活動、健康與體育、本土語沒有段考，平時成績就是定期考查的 100%）。

數字可以直接修改，改完離開欄位就自動儲存；每一組的比例不用剛好是 100，系統會自動換算。某個成分還沒有資料（例如期末考還沒考）時，會自動略過並重新分配其餘比例。項目屬於哪個成分，是看「類別」：名稱含「作業、習作、學習單」＝作業；含「期中、期末」＝段考；含「課堂、參與、發言、討論、表現、口試」＝課堂表現；其他＝平時測驗（可以在分析頁面的設定改）。平時項目屬於第一次還是第二次定期考查，到「項目管理」的「階段」欄設定（預設：期中考之前登記的算第一次，之後的算第二次）。

🎙️ 語音輸入設定 ▾

語音輸入因為麥克風權限限制，不能在這個面板或網頁應用程式網址裡使用，必須開啟成「頂層網頁」——可以是存到自己電腦雙擊開啟，也可以上傳到 GitHub Pages 等網站空間，任何裝置用瀏覽器打開都能用。

需要先完成「部署 → 新增部署作業 → 網頁應用程式」，這個按鈕才抓得到你的專屬網址；還沒部署的話按下去會提示你先部署。如果你已經有一份固定網址在用（例如放在 GitHub Pages），不用每次都重新下載——直接在那份頁面右下角按「⚙️ 連線設定」改網址或密碼即可。

密碼

••••••••

密碼不會寫進下載的檔案或任何頁面原始碼裡（避免萬一放到公開網站外流）。獨立頁面第一次連線時，把這裡的密碼複製貼到它跳出的「連線設定」畫面即可，之後同一台裝置、同一個瀏覽器都不用再輸入。

自動偵測的網址不對時（大多數情況不需要用到這個）

如果下載出來的頁面連線一直失敗，可以在這裡手動指定一次正確的 /exec 網址，之後下載都會固定用這一個。這個設定只存在你自己這份試算表裡，不會被複製到別人建立的副本，可以放心分享範本。

💾 備份（避免資料不小心被刪掉） ▾

把整份試算表複製一份，存到你雲端硬碟的「登記分數備份」資料夾。重要的時間點（例如期中考登記完成、期末結算後）建議手動備份一次並加上備註；平常可以開啟「每週自動備份」。要刪除科目、項目或清空成績之前，也請先備份。

⚠️ 備份功能只能在從試算表選單開啟的面板裡使用。

📌 還原時怎麼做

開啟備份檔，直接當作新的試算表使用，或在備份檔裡選分頁、按右鍵「複製到 → 現有試算表」，把需要的科目工作表複製回來。注意：成績權重、類別分析方式這些設定存在 Apps Script 的「指令碼屬性」，備份檔不會帶著，還原後請到「科目設定 → 學期成績權重」確認一次。

另外，Google 試算表的「檔案 → 版本記錄 → 為目前版本命名」是 Google 自己的功能，沒有開放給程式使用，需要你手動按；這裡的「有備註的備份」可以達到一樣的效果。

📊 資料庫 ▾

「重新整理資料」會重新從試算表讀取科目、類別、學生、語音修正等所有設定，如果懷疑畫面跟試算表不同步，可以按這個。

🔤 語音修正設定 ▾

新增修正對照

語音辨識常會把某些字詞聽成同音的別的字，例如把「98」聽成「酒吧」、把「88」聽成「爸爸」。在這裡新增後，之後語音輸入（含手機聽寫）辨識到的文字，只要含有「原本聽到的文字」都會自動先換成「要修正成的文字」再解析分數，不用每次手動改。
