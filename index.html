登記分數系統

念一句「座號、分數」，成績就寫進 Google 試算表；掃一張考卷，OCR 幫您把分數一次帶入，資料留在您自己的 Sheet 裡。

📄 建立我的範本副本

您會建立自己的副本；不會共用範本原作者的班級與學生資料。

✨ 本系統亮點

從語音登記、拍照辨識到手動輸入，電腦與手機都能快速完成全班成績登記。

🎤

念分數就自動存檔

對著麥克風說「姓名 分數」或「座號 分數」，念完稍停就自動寫入試算表，不用手動一格一格輸入。

📷

掃考卷、OCR 自動帶入

拍一張手寫成績單或考卷，系統自動辨識文字，比對座號姓名後把分數填進成績表。

📚

科目、類別、項目彈性管理

依科目分頁登記，項目可依類別分組、批次產生一整串（例如作業1～作業12），順序也能調整。

🔤

常聽錯的字，自己教它

語音辨識把「88」聽成「爸爸」這類同音誤判，可自訂修正對照表，越用越準確。

🚀 第一次設定與部署

  1. 建立試算表副本

    點上方按鈕，把範本複製到您自己的 Google 雲端硬碟。

  2. 開啟 Apps Script

    在新副本中點選「擴充功能」→「Apps Script」。程式碼已隨範本複製，不需要自己貼上。

  3. 啟用 Drive API 進階服務

    左側「服務」→按「＋」→找到 Drive API → 新增。這是拍照辨識（OCR）需要用到的內建服務，免費。

  4. 新增網頁應用程式部署

    按右上角「部署」→「新增部署作業」，點齒輪並選「網頁應用程式」。

  5. 設定執行與存取權限

    「執行身分」選「我」；「誰可以存取」選「所有人」（語音輸入的獨立頁面需要透過這個網址跟試算表溝通）。

  6. 下載語音輸入專用頁面

    按「部署」完成 Google 授權後，回到試算表選單開啟登記分數面板，進入「系統設定 → 語音輸入專用頁面」按下載，會自動產生已經填好您專屬網址的頁面。

  7. 開啟頁面並輸入一次密碼

    把下載的檔案雙擊開啟（或上傳到 GitHub Pages 等網站空間，見下方說明），第一次要存檔時會跳出視窗要求輸入密碼——回到面板同一張卡片按「顯示」查看、「複製」貼上即可，之後同一台裝置、同一個瀏覽器都不用再輸入。

💡 這一頁只提供範本與說明；真正的成績資料請在您自己部署後，從試算表面板或下載的語音輸入頁面使用。

🎙️ 語音輸入為什麼要另外下載頁面？

這是 Google 的平台限制，不是設定錯了。試算表選單開的面板、甚至直接打開網頁應用程式網址，內容都還是被包在 Google 自己的一層 iframe 裡，瀏覽器規定這種情況下麥克風權限不會往下傳遞。

問題出在「被包在 iframe 裡」，跟檔案實際放在哪裡無關——只要是「頂層網頁」就能正常使用麥克風。所以下載出來的頁面，存在自己電腦上雙擊開啟可以用；上傳到 GitHub Pages、Cloudflare Pages、Netlify 等免費靜態網站空間也一樣可以用，甚至更方便：任何裝置打開網址就能用，瀏覽器通常也只需要允許一次麥克風權限。密碼不會寫進這份檔案裡（就算放在公開網站上也不會外洩），而是輸入一次後存在瀏覽器裡。拍照辨識與手動輸入則不受此限制，可直接在試算表面板中使用。
