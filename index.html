🎙️ 語音輸入專用頁面 ▾

語音輸入因為麥克風權限限制，不能在這個面板或網頁應用程式網址裡使用，必須開啟成「頂層網頁」——可以是存到自己電腦雙擊開啟，也可以上傳到 GitHub Pages 等網站空間，任何裝置用瀏覽器打開都能用。下載按鈕在最上方「目前科目」那一列的右邊（⬇️ 下載語音輸入用的網頁），需要先完成「部署 → 新增部署作業 → 網頁應用程式」，這個按鈕才抓得到你的專屬網址；還沒部署的話按下去會提示你先部署。

你的密碼： ••••••••

下載的檔案不會寫死密碼（避免萬一放到公開網站外流），語音輸入頁面第一次要存檔時會跳出畫面要你輸入密碼，把這裡的密碼複製貼上即可，之後同一台裝置就不用再輸入。

大多數情況不需要用到下面這個。只有下載出來的網址一直不對（例如連線一直失敗）時，才需要手動指定一次正確的 /exec 網址。這個設定只存在你自己這份試算表裡，不會被複製到別人建立的副本，可以放心分享範本。

🔤 語音修正設定 ▾

新增修正對照

語音辨識常會把某些字詞聽成同音的別的字，例如把「98」聽成「酒吧」、把「88」聽成「爸爸」。在這裡新增後，之後語音輸入（含手機聽寫）辨識到的文字，只要含有「原本聽到的文字」都會自動先換成「要修正成的文字」再解析分數，不用每次手動改。

🎤 語音輸入

⚠️ 這個面板（從試算表選單開啟的）沒辦法使用語音輸入，麥克風權限會被 Google 的畫面擋住。請按上方「目前科目」那一列右邊的「⬇️ 下載語音輸入用的網頁」，開啟下載出來的檔案才能使用語音輸入；密碼可以在「系統設定」頁籤查看並複製。

建議唸法：「姓名 分數」，例如：「王小明 85」；分數固定念兩位數，10分以下請念成兩位數（例如5分念「05」），連續念多筆不用特別停頓也能正確分辨。僅支援電腦版／Android 版 Chrome 瀏覽器，需允許麥克風權限。

📱 手機請改用這個：iPhone 完全不支援本頁語音辨識；Android 也可能因權限限制無法使用。點下面欄位、再點手機鍵盤上的🎤聽寫圖示口述（例如：「3號 85 4號 90 5號 78」），說完按「解析並套用」，不受瀏覽器語音辨識限制影響。

不用念項目名稱也不用念序號，照勾選順序直接念分數，每個分數固定兩位數字，100 請念「一百」，例如念「九八」代表 98、念「八七」代表 87：「九八，八七，七六...」念完稍停即可接著念下一個，念錯可按「回上一項」重念。僅支援電腦版／Android 版 Chrome 瀏覽器。

📱 手機請改用這個：iPhone 完全不支援本頁語音辨識；Android 也可能因權限限制無法使用。點下面欄位、用手機鍵盤🎤聽寫圖示口述，說完按「解析並套用」，不受瀏覽器語音辨識限制影響。
